# TikTok Cookies para Projecto 9x

Para habilitar la creación automática de salas en TikTok LIVE y la autenticación sin interfaz gráfica (Headless), coloca aquí tu archivo `tiktok_cookies.json` exportado desde tu navegador con una extensión como "Cookie-Editor" (formato JSON).

Las cookies esenciales requeridas por el motor son:
- `sessionid`
- `ttwid`
- `sid_guard`
- `sid_tt`
